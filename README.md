# Forge Combat Helper 0.3.1

Узкая панель мастера Owlbear Rodeo: спасы через Dice+, применение урона к Forge.

## Использование
Включите Forge, Dice+ и расширение. Щит справа открывает панель шириной 270 px, не переключая текущий инструмент карты.
Используйте обычное выделение Owlbear: кликом, с модификаторами или рамкой. Цели автоматически повторяют выделение. Снятие выделения очищает цели. Токены без Forge игнорируются.
Введите спас, СЛ, урон. Урон — готовое целое число (28) или формула (3d6+4). Число используется напрямую; формулы и все спасы проходят через Dice+. При недоступности Dice+ локального запасного броска нет.
Выберите эффект успешного спасброска (половина / без урона / полный). Для цели можно указать преимущество/помеху и защиту ×1/½/0/×2. Сопротивления Forge видны при наведении на имя; автоматически не применяются.
«Бросить» показывает результаты; «Применить» списывает сначала временные, потом обычные хиты; «↶» отменяет последнее применение, если хиты с тех пор не менялись. При смене выделения результаты сбрасываются, чтобы не применить их к другой группе.
Dice+ · мне/всем — видимость бросков. Пресетов и отдельного режима целей нет.

## Установка
Vercel: статический сайт без сборки, конфигурация в vercel.json.
Добавьте https://ВАШ-ДОМЕН/manifest.json в Owlbear. После обновления перезагрузите комнату.
SDK 3.1.0 включён локально; SDK-LICENSE.txt.

## Ограничения
Только мастер. Нет обычных атак, автоматического поиска целей в области, расхода ячеек, концентрации и особых способностей.
При закрытии панели результаты и отмена теряются. Не редактируйте хиты одновременно с другого клиента: SDK не предоставляет транзакционную блокировку. Перед применением проверяются текущие хиты.
Поля Forge: HP Z005, максимум Z006, временные Z042, спасы Z023–Z028.

## Проверки
npm test — арифметика, временные хиты, Dice+ handshake, сопоставление ответов, ошибки и таймауты. Живую интеграцию проверяйте в комнате.

Если спас не заполнен, используется floor((характеристика − 10) / 2). Если нет и характеристики — модификатор 0. Явно записанный спас 0 сохраняется. Некорректные значения обрабатываются как отсутствующие; бонус мастерства не добавляется автоматически.
