# Forge Combat Helper 0.2.0

Компактная панель мастера Owlbear Rodeo: массовые спасы через Dice+ и урон в Forge.

## Использование
1. Включите Forge, Dice+ и это расширение в комнате.
2. Нажмите щит справа. Нажимайте токены: один клик добавляет цель, повторный убирает. Кнопка «◎ Цели» возвращает режим выбора, если вы переключились на другой инструмент карты.
3. Панель остаётся открытой при клике на карту (`disableClickAway`). Для перемещения карты используйте обычный инструмент руки. Потеря стандартного выделения не стирает список целей.
4. «↻» загружает обычное выделение Owlbear. Можно также выделить токены до открытия панели.
5. Укажите спас, СЛ, урон и результат успешного спасброска. Для каждой цели доступны обычный бросок/преимущество/помеха и множитель защиты ×1/½/0/×2. Сопротивления Forge видны при наведении на имя; автоматически не применяются.
6. «Бросить» отправляет в Dice+ один общий бросок урона, затем массовый бросок спасов. При недоступности Dice+ локального запасного броска нет. «Dice+ · мне/всем» управляет видимостью.
7. Проверьте результаты и нажмите «Применить». Сначала расходуются временные хиты, потом обычные. «↶» отменяет последнее применение, если хиты с тех пор не изменились.
8. «＋» сохраняет действие под указанным названием в этом браузере.

## Установка / Vercel
Статический сайт, без сборки. `vercel.json` задаёт конфигурацию и CORS/iframe заголовки.
Добавьте `https://ВАШ-ДОМЕН/manifest.json` в Owlbear. После обновления перезагрузите комнату.
SDK 3.1.0 включён локально, лицензия — SDK-LICENSE.txt.

## Ограничения
Только мастер. Нет обычных атак, автопоиска целей в области, расхода ячеек, концентрации и автоматической обработки особенностей. Броски и результат Dice+ сопоставляются по уникальному rollId; группы спасов — по меткам FC0, FC1 и т.д.
Закрытие панели сбрасывает результаты/отмену. Один мастер применяет урон за раз: API не гарантирует транзакционную блокировку между клиентами. Перед записью проверяются текущие хиты.
Поля Forge: HP Z005, максимум Z006, временные HP Z042, спасы Z023–Z028. Данные персонажей не мигрируются.

## Проверки
`npm test`: арифметика урона, временные хиты, Dice+ handshake, корреляция ответов, ошибки/таймауты, сопоставление массовых спасов.
Интерфейс дополнительно проверен с имитацией SDK/Dice+ (выбор/снятие целей, сохранение при потере фокуса, применение/отмена, отказ при изменившихся хитах). Живую интеграцию необходимо проверить в комнате.
