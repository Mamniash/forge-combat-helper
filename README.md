# Forge Combat Helper — 0.1.0

Прототип расширения Owlbear Rodeo для мастера. Кнопка щита с кубиком в правой панели инструментов. Точный порядок кнопок определяет Owlbear.

## Установка
Разместите содержимое папки на статическом HTTPS-хостинге, в корне отдельного сайта. Сборка не требуется; SDK 3.1.0 включён локально. Хостинг должен разрешать загрузку страниц в iframe и чтение manifest.json из Owlbear (CORS). Заголовки в `_headers` подходят хостингам, поддерживающим такой файл. На других настройте их отдельно.
Добавьте URL `https://ВАШ-ДОМЕН/manifest.json` в список расширений Owlbear и включите расширение в комнате. Откройте сцену от имени мастера. Нажмите новую иконку щита справа.
Не устанавливайте ZIP напрямую: Owlbear требует опубликованный URL manifest.json.

## Использование
1. Выделите на карте токены с данными Forge.
2. Откройте щит, нажмите «Загрузить выделенные».
3. Выберите сохранённое действие или настройте спас, СЛ, урон и эффект успешного спасброска.
4. Вручную отметьте преимущество/помеху и защиту каждой цели. Сопротивления из Forge показаны для справки, не применяются автоматически.
5. Бросьте спасы и общий урон; при необходимости измените урон каждой цели.
6. Примените. Сначала расходуются временные хиты, затем обычные. Есть отмена последнего применения, пока панель открыта и хиты не были изменены.
7. Перед следующим броском заново загрузите выделенные цели.

## Ограничения прототипа
- Не проверен в живой комнате пользователя. Сначала испытайте на копиях токенов.
- Только мастер; броски локальны, не отправляются в Dice+. Игроки видят изменённые хиты через Forge согласно его настройкам.
- Нет обычных атак, автопоиска целей в области, расхода ячеек, концентрации, автоматических особенностей, сопротивлений и разбора Actions.
- Пресеты сохраняются в этом браузере. Результаты и отмена исчезают при закрытии панели.
- Используйте одного мастера для применения урона. SDK не предоставляет здесь транзакционную блокировку между клиентами: не редактируйте хиты одновременно.
- Все поля соответствуют предоставленному шаблону Forge: HP Z005, max HP Z006, temp HP Z042, спасы Z023–Z028.
- Исходный экспорт Гона не изменён. Поле Z042=6 трактуется именно как временные хиты; исправьте его в Forge, если это единицы чародейства.

## Проверки
`node --test test.mjs` — расчёты, округление, временные хиты, преимущество и валидация.
`python3 -m http.server 8080` — локальная раздача файлов (не заменяет публичный HTTPS-хостинг).
